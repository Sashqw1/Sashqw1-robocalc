# site/

Публикуемая часть: `index.html` — карта экранов и оба вайрфрейма одной
самодостаточной страницей. Открывается двойным кликом локально и она же
уезжает на GitHub Pages воркфлоу `.github/workflows/deploy.yml`.

Единственная внешняя зависимость — mermaid с cdnjs для графа переходов.
Без интернета в блоке остаётся исходный текст диаграммы, он тоже читается.

Исходные документы, из которых собрана страница, лежат в `../docs/`.

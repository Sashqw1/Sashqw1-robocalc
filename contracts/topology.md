# topology.py — контракт 6: TopologyConfig / SceneData

Граница: **Алексей ↔ Владимиров**, Алексей (editor2d) **→** Стас (simulation).

В [api-routes.md](../api-routes.md) эта же модель называется **Scene** —
`Scene = TopologyConfig`, переименования нет.

**Версия 2 (24.09.2026)** по заявке Алексея: границы объекта, подложка-чертёж
**ссылкой** (сам файл грузится отдельной ручкой), названия у элементов,
направление и привязка маршрутов, места у зарядки, вид и поворот робота,
пустой `catalog_item_id` разрешён.

## Point2D
| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| x | float | да | Координата X в системе координат сцены |
| y | float | да | Координата Y в системе координат сцены |

## Bounds
Границы объекта — прямоугольник сцены в метрах.

| Поле | Тип | Обязательное/по умолчанию | Описание |
|---|---|---|---|
| origin | Point2D | `{0,0}` | Левый верхний угол |
| width_m | float | да | Ширина, м |
| height_m | float | да | Глубина, м |

## SceneBackground
Подложка: скан или чертёж, по которому рисуют. **Внутри плана только ссылка** —
файл грузится через `POST /api/projects/{id}/scene/background` и при каждом
сохранении плана заново не передаётся.

| Поле | Тип | Обязательное/по умолчанию | Описание |
|---|---|---|---|
| background_id | str | да | Идентификатор загруженного файла |
| url | str | да | Ссылка для показа в редакторе |
| width_px, height_px | int | да | Размер картинки |
| scale_m_per_px | float | да | Калибровка: сколько метров в пикселе |
| offset | Point2D | `{0,0}` | Смещение подложки в координатах сцены, м |
| rotation_deg | float | `0` | Поворот подложки |
| opacity | float | `0.5` | Прозрачность, 0…1 |

|---|---|---|---|
| id | str | да | Идентификатор стены |

## Zone

|---|---|---|---|
| id | str | да | Идентификатор зоны |

## Route
| Поле | Тип | Обязательное/по умолчанию | Описание |
|---|---|---|---|

| points | list[Point2D] | да | Ломаная маршрута |
| direction | str | `two_way` | `two_way` / `one_way` — от первой точки ломаной к последней |

## OperationPoint
| Поле | Тип | Обязательное/по умолчанию | Описание |
|---|---|---|---|
| id | str | да | Идентификатор точки |

| position | Point2D | да | Координаты точки |
| capacity | int | `1` | Сколько роботов обслуживается одновременно; для зарядки — число мест |

## RobotPlacement
| Поле | Тип | Обязательное/по умолчанию | Описание |
|---|---|---|---|
| id | str | да | Идентификатор размещения робота на сцене |
| name | str \| null | null | Название («AMR-3») |
| catalog_item_id | str | `""` | Ссылка на позицию каталога. **Пусто допустимо** — робот «вообще», без конкретной модели (черновик плана до шага 4) |
| category_id | str \| null | null | id из `categories.json` → `equipment_categories`: вид робота, когда модель не выбрана |
| start_position | Point2D | да | Стартовая позиция на сцене |
| start_rotation_deg | float | `0` | Поворот на старте, градусы; 0 — вдоль оси X |
| charging_point_id | str \| null | null | `OperationPoint.id` зарядки, к которой привязан робот |

## TopologyConfig (корневая модель, она же Scene)
| Поле | Тип | Обязательное/по умолчанию | Описание |
|---|---|---|---|
| id | str | да | Идентификатор конфигурации сцены (присваивает сервер) |
| project_id | str | да | Идентификатор проекта |
| scale_m_per_unit | float | `1.0` | Метров на единицу координат сцены |
| bounds | Bounds \| null | null | Границы объекта; если не заданы — считаются по контуру стен |
| background | SceneBackground \| null | null | Подложка-чертёж: **только ссылка**, не сам файл |
| walls | list[Wall] | [] | Стены и контур здания |
| zones | list[Zone] | [] | Зоны объекта |
| routes | list[Route] | [] | Маршруты |
| operation_points | list[OperationPoint] | [] | Точки операций и зарядки |
| robots | list[RobotPlacement] | [] | Размещённые роботы |

## Проверки плана

Предупреждения (маршрут через стену, робот в запретной зоне и т. п.) считает
**сервер** и возвращает в `ProjectState.scene.warnings` — см.
`SceneWarning` в [project_state.md](project_state.md). Редактор может
дублировать их локально для мгновенной подсветки, но источник истины — ответ
сервера: те же предупреждения увидит симуляция и отчёт.
